# 油电猫饼

一个用于记录燃油车 / 电动车补能与能耗数据的离线 Android App。「油电猫饼」这个名字带一点“有点毛病”的谐音梗。

## 功能

- 多车辆管理，分别支持燃油车与电动车
- 记录加油或充电，支持历史补录
- 按车辆查看油耗 / 电耗、累计数据和历史记录
- 分类型查看近期价格趋势
- 基于历史补能区间估算满油 / 满电续航
- 所有数据仅保存在设备本地

## 特点

- 完全离线，无需账号或服务器
- 不上传车辆与补能数据
- 使用 Room 进行本地存储
- 使用 Jetpack Compose 与 Material 3 构建界面

## 构建

开发环境：Android Studio、JDK 17、Android SDK（compile / target SDK 35）。

```bash
./gradlew assembleDebug
```

Release 签名凭据不会包含在本仓库中；正式发布包应使用私有本地签名配置构建，并作为 GitHub Release 的附件分发。

## 数据与隐私

应用数据使用 Room 存储在设备本地。仓库不包含用户数据库、设备备份或真实补能记录；首次安装时车辆与补能记录均为空。
